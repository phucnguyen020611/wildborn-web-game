## Ghi công bắt buộc (CC-BY)

Hiện không có asset CC-BY nào (cáo Khronos đã được thay ngày 2026-10-19). Khi thêm asset CC-BY, ghi dòng ghi công vào đây để đưa lên màn hình credits.

Ghi công tự nguyện (CC0, không bắt buộc nhưng nên có): Quaternius (MegaKit, bộ thú, Universal Base Characters, Universal Animation Library), Kenney, artisticdude, TinyWorlds, para / MakeHuman, Poly Haven (Charlotte Baglioni, Rob Tuytel, Rico Cilliers, Amal Kumar).

## Quy trình

1. Kiểm tra giấy phép theo checklist spec mục 17.3, ghi một dòng vào bảng trên.
2. Đặt file nguồn vào `art-source/<loại>/` theo quy tắc tên (`crt_`, `wpn_`, `env_`, `chr_`).
3. Chạy `npm run assets` → file tối ưu ra `src/assets/` (cùng đường dẫn).
4. Import trong code bằng `import url from './assets/.../x.glb?url'` để Vite gắn hash vào tên file.
